PEOPLE HUB MOCKUP

Open site/index.html to review the hub. All five sidebar categories and
twelve profile links open static pages. No dependencies or backend are needed.

The markup follows the existing NDT4 header, page, section navigation, and
People Card components. The official NDT4 stylesheet loads from:
https://conductor.nd.edu/stylesheets/themes/ndt/4.0/ndt.css

assets/site.css holds small mockup-specific additions. assets/fallback.css
loads only if the official stylesheet fails, allowing an offline preview.
The fallback is an approximation and is not the official NDT4 stylesheet.

People and roles are fictional. All profile images use a neutral placeholder.
The wide photo is reused from the existing saved People mockup in this
workspace (mockups/people.html); it depicts scholars, not the sample profiles.
Notre Dame marks are reused from exemplar/assets, originally obtained from
webtheme.nd.edu. This page is labeled as a mockup and requests no indexing.

Rebuild: python3 build.py
Publish: sh publish.sh
Optional: sh publish.sh OWNER/DIFFERENT-REPOSITORY-NAME

Publishing requires network access to GitHub and an authenticated GitHub CLI
account able to create a public repository and enable GitHub Pages.
If needed, authenticate in your terminal using gh auth login first.
The publishing script creates a separate public repository and enables Pages
with GitHub Actions. Only files in this standalone folder are committed.
The GitHub Actions workflow publishes site/ on pushes to main.
The workflow and Pages setup follow GitHub's documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
https://docs.github.com/en/rest/pages/pages#create-a-github-pages-site

This session's shell could not resolve api.github.com or conductor.nd.edu.
The connected GitHub app can edit its accessible private repository but
exposes no repository creation or GitHub Pages administration capability.

Validation in this session: 18 generated HTML pages, 268 local links, and 91
image references checked without errors. One main heading per page and image
alt attributes were checked. Browser rendering could not be verified because
Chrome and Quick Look were blocked by this session's sandbox. NDT4 styling
therefore needs a connected-browser visual check before treating this as final.
