People hub usability alternatives

Generated by comparison.py through build.py. Run python3 build.py to rebuild.
Routes: /compare/ and /compare/{small,directory,gateway,featured,category}/.
All alternatives use NDT3 to isolate behavior from theme appearance.
The main three theme variants remain separate and now start directly at the directory.
Data: 2,040 deterministic fictional profiles; 1,773 current and 267 past. The small example uses the existing 13 fictional mock profiles.
Search matches names, role, discipline, region and research interest; filters combine with AND. Results use surname ordering and 24 profiles per page. URL parameters preserve query, filters and pagination on reload. Profile buttons open native dialogs.
Sidebar parent pages retain the established default subgroup behavior. Child groups expand for the selected parent. No category is selected on a hub. The category demonstration intentionally starts within Faculty.
Test tasks: known-person lookup (Amara A. Adams), migration expertise, combined Political Science/Latin America filters, past affiliation, category/subcategory switching, pagination, empty states, and mobile menu.
These are static client-side mockups, not a production search backend. No real directory data is imported.
